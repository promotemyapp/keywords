# Agent guidance

This repository provides keyword-research guidance and an API for producing reusable keyword briefs. It does not draft, publish, or validate blog-post templates.

- Use `researcher.md` for the research workflow.
- Use `api-implementation.md` when changing the API.
- Keep source provenance and unresolved questions visible in each brief.
- Treat autocomplete suggestions and Trends signals as directional evidence with a captured date.
