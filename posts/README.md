# Posts

This directory is reserved for future blog and social media post concepts in OKF format. Start from [`../templates/post-core.md`](../templates/post-core.md), then apply either the [`blog-post.md`](../templates/blog-post.md) or [`social-media-post.md`](../templates/social-media-post.md) extension.

Each post should be a Markdown concept document with YAML frontmatter and a descriptive `type`, such as `Blog Post` or `Social Media Post`. Keep `index.md` and `log.md` reserved for their OKF-defined purposes.
